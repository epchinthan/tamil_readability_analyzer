Tamil ASR Setup

Reading Practice needs a local/server speech-to-text engine before it can score recorded child speech. The scoring fallback still works if you paste a Tamil transcript manually.

Recommended high-quality path: install a Tamil-capable ASR engine, then set one of these before starting the app: 
export WHISPER_CPP_BIN=/path/to/whisper-cli
export WHISPER_CPP_MODEL=/path/to/ggml-small-or-medium.bin

# Or use any custom Tamil ASR command that prints transcript text:
export TAMIL_READING_ASR_CMD="/path/to/asr --lang {lang} --audio {wav}"

Let's load your textbooks to get started

The app uses the textbooks_imported/ folder inside the app directory as its default location — this is the same folder the Textbook Auto Importer tab downloads into from internet sources.

To get started: copy your Tamil textbook PDFs into textbooks_imported/, or enter a custom folder path below. Everything is read only from your machine — no internet needed for this step.
